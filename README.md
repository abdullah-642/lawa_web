# لواء كونسبت — Liwa Concept Design

موقع احترافي ثنائي اللغة (عربي / إنجليزي) بهوية ثلاثية الأبعاد لشركة لواء كونسبت.

## التشغيل

افتح ملف `index.html` مباشرة في المتصفح (دبل كليك) — الموقع يعمل بدون أي خادم.

> **للحصول على أفضل أداء (3D + الخطوط)** ينصح بتشغيل خادم محلي بسيط:
> ```powershell
> # في PowerShell من مجلد المشروع:
> python -m http.server 8000
> ```
> ثم افتح: http://localhost:8000

## إضافة شعار الشركة

1. احفظ ملف الشعار باسم `logo.png` داخل مجلد `assets/`
   → المسار النهائي: `assets/logo.png`
2. الموقع سيعرضه تلقائياً في الهيدر.
3. لإزالة الخلفية البيضاء فعلياً (وليس فقط بصرياً):
   - استخدم أداة مجانية: https://www.remove.bg
   - أو في Photoshop: Select Subject → Layer Mask
   - احفظ الملف بصيغة PNG شفاف ثم استبدل `assets/logo.png`

> **ملاحظة:** الموقع يستخدم `mix-blend-mode: multiply` ليُخفي الخلفية البيضاء بصرياً حتى لو لم تكن شفافة، لذا الشعار سيظهر نظيفاً على خلفية الموقع الكريمية مباشرة.

## إضافة شعارات العملاء

1. ضع شعارات العملاء داخل مجلد `assets/clients/`
2. سمِّها بالترتيب: `logo1.png`، `logo2.png`، ... حتى `logo8.png`
3. الموقع سيربطها تلقائياً ويعرضها في قسم "عملاؤنا".

## تغيير رقم الواتساب

افتح `index.html` وابحث عن `966544668836` واستبدله بالرقم الجديد (3 مواضع).

## تخصيص النصوص

كل النصوص العربية والإنجليزية موجودة في ملف `i18n.js` — حدّث المفاتيح هناك دون الحاجة لتعديل الـ HTML.

## بنية المشروع

```
lawa/
├── index.html        ← الصفحة الرئيسية
├── styles.css        ← الهوية البصرية والتنسيقات
├── script.js         ← المشاهد ثلاثية الأبعاد والتفاعلات
├── i18n.js           ← نصوص اللغتين العربية والإنجليزية
├── README.md         ← هذا الملف
└── assets/
    ├── logo.png      ← (يُضاف من قبلك) شعار الشركة
    └── clients/
        ├── logo1.png ← (تُضاف من قبلك) شعارات العملاء
        ├── logo2.png
        └── ...
```

## المزايا التقنية

- **ثلاثي الأبعاد:** عناصر معمارية تتحرك مع حركة الفأرة (Three.js)
- **ثنائي اللغة:** تبديل فوري عربي ↔ إنجليزي مع تغيير اتجاه الصفحة
- **متجاوب:** يعمل على الجوال، التابلت، والديسكتوب
- **متحرك:** انتقالات GSAP احترافية وعدادات أرقام
- **زر واتساب عائم:** اتصال فوري + نموذج تواصل يُرسل عبر واتساب
- **بدون مكتبات بناء:** HTML/CSS/JS خام — قابل للنشر مباشرة على أي استضافة (Netlify, Vercel, GitHub Pages).
